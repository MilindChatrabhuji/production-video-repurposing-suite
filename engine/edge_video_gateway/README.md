## 🌟 Executive Overview
The **Video Edge Gateway & Metadata Engine** provides a serverless Cloudflare Workers API for generating high-CTR YouTube Shorts titles, viral TikTok descriptions with hashtag clusters, signed cloud upload URLs, and render job queue tracking.

## 🚀 Key Modules
1. **`video_metadata_generator.ts`**:
   - Generates platform-optimized titles (< 50 chars for Shorts), TikTok captions, and LinkedIn executive posts.
2. **`webhook_dispatcher.ts`**:
   - Manages R2/S3 storage presigning and async render job completion callbacks.
3. **`worker.ts`**:
   - Serverless REST API router serving `/health`, `/api/v1/segment`, `/api/v1/caption`, `/api/v1/export-specs`, `/api/v1/render-job`, and `/api/v1/retainers`.
